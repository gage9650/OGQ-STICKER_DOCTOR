# 🩺 OGQ Sticker Doctor

> **AI를 활용하여 OGQ 스티커를 업로드 전에 자동으로 검수하는 웹 애플리케이션**

OGQ Sticker Doctor는 **OGQ 스티커 마켓에 업로드하기 전**, 이미지가 심사 기준을 충족하는지 자동으로 검사하고 AI를 통해 개선점을 제안하는 웹 애플리케이션입니다.

매번 직접 확인해야 했던 이미지 규격, 투명 배경, 여백 등을 자동으로 검사하며, AI가 스티커의 품질과 가독성까지 분석하여 보다 높은 완성도의 스티커 제작을 지원합니다.

---

# ✨ 주요 기능

## 📏 OGQ 심사 규격 자동 검사

업로드한 이미지를 분석하여 OGQ 심사 기준을 충족하는지 확인합니다.

* PNG 파일 형식 검사
* 이미지 해상도 확인
* 파일 용량 검사
* RGB / RGBA 컬러 모드 확인
* 투명 배경 여부 검사
* 이미지 여백(비율) 분석

---

## 🧠 AI 심층 진단

Google Geminai AI를 활용하여 스티커의 품질을 분석합니다.

다음 항목들을 자동으로 확인합니다.

* 심사 리스크 분석
* 글씨 가독성
* OCR 기반 오탈자 검사
* 다크모드 가독성
* 디자인 품질 분석
* 개선 방향 제안

---

## 📂 제출 구성 확인

OGQ 제출에 필요한 이미지가 모두 준비되었는지 확인합니다.

* 스티커 이미지

누락된 이미지가 있다면 즉시 알려줍니다.

# 💡 프로젝트를 만든 이유

OGQ 스티커를 제작할 때는 이미지 규격, 배경, 여백, 가독성 등을 직접 확인해야 하며, 이러한 작업은 반복적이고 시간이 많이 소요됩니다.

OGQ Sticker Doctor는 이러한 과정을 자동화하여 제작자가 업로드 전에 문제점을 빠르게 발견하고 수정할 수 있도록 돕기 위해 개발되었습니다.

단순히 규격을 검사하는 것을 넘어 AI를 활용하여 품질까지 함께 분석하는 것을 목표로 합니다.

# 🆕 VER2 기반 추가 기능

## 1. OGQ 시장 비교
사용자가 스티커의 느낌과 태그를 입력하면 OGQ Sticker Search API로 관련 콘텐츠를 검색하고, AI가 검색 결과의 제목·설명 등 확인 가능한 정보를 바탕으로 공통점·차이점·장점·보완점을 정리합니다.

## 2. 검사 기준 커스텀
OGQ 공개 제작 가이드 기준을 내부 프리셋으로 저장해 두고, 사용자가 검사 영역을 체크리스트로 선택할 수 있습니다. 별도의 사용자 기준도 한 줄씩 추가할 수 있습니다.

> 참고: OGQ의 비공개 내부 심사 매뉴얼을 구현했다고 주장하지 않습니다.

## 3. AI 문제 위치 표시
Gemini가 찾은 문제를 구조화된 결과로 받아 이미지 위에 빨간색 영역으로 표시하고, 각 문제에 대해 `어디가 / 왜 / 어떻게`를 함께 보여줍니다. 위치 표시는 AI의 참고용 시각화입니다.

## 🔐 Streamlit Secrets

다음 값을 Streamlit Cloud의 Secrets에 넣어야 합니다.

```toml
GEMINI_API_KEY = "..."
OGQ_API_KEY = "..."
OGQ_API_BASE_URL = "https://oapi.ogq.me"
OGQ_USER_ID = "sticker-doctor"
```

API 키는 코드와 GitHub에 저장하지 마세요.
